# Sete Passos

Site institucional da Sete Passos, voltado a fisioterapia e estética avançada.

O código-fonte do projeto está no arquivo [sete-passos-site-source.zip](sete-passos-site-source.zip). Baixe o arquivo e extraia para abrir a estrutura completa do projeto. Capturas e backups de desenvolvimento foram deixados de fora do pacote.

Site: https://sete-passos.pages.dev/

## Conteúdo

O pacote inclui as páginas, estilos, scripts, assets usados pelo site e documentação do projeto.
